# Scope and phase board

| Phase | P0 owner (engineering role) | Deliverable and acceptance evidence |
|---|---|---|
|0|Architect|Requirements, ADRs, reference inspection, traceability|
|1|DevOps|Independent Next/React strict TS repo; install, lint, typecheck, build|
|2|Frontend|Editorial responsive shell, themes, keyboard navigation; screenshots|
|3|Content engineer|Discriminated schemas, IDs, taxonomy, graph and redirects; invalid fixtures rejected|
|4|Content engineer|Trusted MDX/math/TOC/citations and draft exclusion; compile tests|
|5|Frontend|Home, hubs, profiles, contact, purposeful empty states; route checks|
|6|Full stack|Search, URL filters, relationships, paths; relevance/visibility tests|
|7|Frontend|Consent video registry and fallback; mocked playback tests|
|8|Math/QA|Secant lab; analytic, constant, cusp and zero-step tests|
|9|Content engineer|Inquiry provenance, revision, reproducibility and truthful labels|
|10|Security/QA|SEO, CSP, legal, print, accessibility, performance evidence|
|11|QA|Audience E2E, screenshots, link crawl and release report|
|12|DevOps|Hosting config, rollback/restore, live verification if accounts available|
|13|Operations|Triage, monitoring and upgrade cadence; no unapproved P1 expansion|

P1 backlog: additional labs, visual graph, optional local reading history, exports, glossary, analytics and editorial UI. P2: CMS, collaborators, Urdu, PWA, progress, feedback, exercises, newsletters. P3: accounts, persistence, database, AI tutor, mobile app. These remain unimplemented unless separately authorized.

Risks: missing v1.1; absent approved contact/channel/CV/domain; hosting and GitHub ownership credentials; human mathematical review; manual screen-reader verification; dependency churn. Mitigate with explicit configuration, locked installs, truthful empty states, automated gates and recorded external blockers.
