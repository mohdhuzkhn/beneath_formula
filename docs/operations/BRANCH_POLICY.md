# Repository policy

Default branch main. Use small phase/feature branches and traceable commits. Require the Quality gates / verify status and owner review for content or code. CODEOWNERS names the authenticated repository owner. Prevent force pushes and branch deletion. Do not supply production secrets to pull_request code from forks.

Where the account plan cannot enforce protected branches on a private repository, retain private visibility and record that limitation rather than making the repository public or claiming protection is active. Configure equivalent owner-controlled review discipline until the plan or hosting policy supports enforcement.
